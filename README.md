# EyeCGas 2 Camera Software Releases

This repository is for software releases for Opgal's EyeCGas 2 camera.

## Software releases

Browse the [Releases page](https://github.com/OPGAL-OPTRONIC-INDUSTRIES-LTD/EyeCGas2-Software/releases) for published software versions and any accompanying release notes or files.

Before updating, confirm that the release is compatible with your camera and follow the instructions provided with the release or by Opgal.

## Camera overview

Opgal's [EyeCGas 2.0 VOC](https://www.opgal.com/blog/optical-gas-imaging-ogi/ogi-part-3-opgal-eyecgas-product-line/) is a handheld optical gas imaging (OGI) camera for locating methane and other volatile organic compound (VOC) leaks during leak detection and repair (LDAR) inspections. The [EyeCGas app](https://www.opgal.com/blog/news/introducing-the-eyecgas-app-for-the-remote-management-of-eyecgas-2-0/) supports remote camera control, live streaming, and image and video capture from a phone or tablet.

Opgal's [EyeCGas Multi product page](https://www.opgal.com/product/eyecgas-multi/) highlights:

- Operator-replaceable spectral filters for different gases, including an optional carbon dioxide filter.
- Built-in gas quantification.
- IP65 dust and water protection.

The linked product page describes EyeCGas Multi; confirm which features apply to your EyeCGas 2 camera and software version.
